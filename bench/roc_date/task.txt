【不要使用任何工具、不要建立或執行檔案，直接寫出程式碼】

用 Python 3.12 寫一個函式 `roc_to_iso(s: str) -> str | None`，把台灣的民國日期字串轉成西元 ISO 日期 "YYYY-MM-DD"。
只能用標準函式庫。規格：

1. 可接受的格式（前後可有空白）：
   - 「民國115年10月14日」「115年10月14日」（「民國」可有可無）
   - 「115/10/14」「115.10.14」「115-10-14」（三段用同一種分隔符號）
   - 月、日可以有前導零（「115/01/05」），年也可以（「0115/01/05」）
2. 數字可以是半形、全形（「１１５／１０／１４」，全形斜線也要接受），
   或國字：〇一二三四五六七八九十百，含「元」。例如「一一五年十月十四日」「一百一十五年十月十四日」「民國元年一月一日」。
   國字只出現在「年月日」格式，不會出現在分隔符號格式。
3. 民國元年 = 1912 年。民國年 = 西元年 − 1911。
4. 下列情況回傳 None：日期不存在（例如 112/02/29、113/04/31、115/13/01）、民國 0 年或負數、
   「民國前」開頭、格式不符、空字串、年月日缺任何一段、混用不同分隔符號（「115/10-14」）。
5. 不要丟出例外；任何無法解析的輸入都回傳 None。

只輸出程式碼本身（含必要的 import），不要寫測試、不要寫說明。
